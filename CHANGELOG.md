# Changelog

{: .no_toc }

All notable changes to this guide are recorded here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
aims to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html) read against the guide
content: **MAJOR** for a restructure of the guide, **MINOR** for new or substantially revised
settings or sections, **PATCH** for wording fixes, link updates and corrections.

Each release records the date its public Microsoft Learn sources were reviewed.

## [1.0.0] - 2026-10-27

Public documentation reviewed 2026-10-27.

### Added

- Self-contained technical guide covering 27 settings in five groups: Phase 1 - Start here,
  Phase 2 - Expand protection, Phase 3 - Broader security, Other identity controls and Teams Rooms
  guidance.
- Settings explorer with search and filters for group, product, admin surface, impact, reversal and
  type, and an accessible detail view for each setting.
- Configuration guidance for the whole organization with Baseline Security Mode and, for the Office
  settings, for specific groups of users with Office Cloud Policy.
- Impact and reversal guidance that separates reversible, permanent and service-managed settings.
- Products and admin surfaces view and a copyable deployment plan.
- GitHub Pages site, MIT license and project documentation.
